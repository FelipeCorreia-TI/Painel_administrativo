# 🎛️ Painel Administrativo Responsivo

## 📖 Sobre o Projeto
Este projeto consiste em um **painel administrativo moderno e responsivo**, desenvolvido com foco em organização de layout, usabilidade e boas práticas de CSS.

A aplicação simula um dashboard utilizado em sistemas reais, contendo menu lateral, cabeçalho interativo e área principal com cards informativos.

O principal objetivo foi praticar conceitos fundamentais de **CSS Grid, Flexbox, responsividade e animações**, criando uma interface limpa e funcional.

---

## 🛠️ Tecnologias Utilizadas
- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries (Responsividade)
- Animações com `@keyframes`

---

## ⚙️ Funcionalidades
- 📌 Menu lateral fixo para navegação
- 📊 Cards informativos no painel principal
- 🎨 Cabeçalho com gradiente moderno
- 🖱️ Botão com efeito de transição suave (hover)
- 📱 Layout responsivo (adaptação para dispositivos móveis)
- ✨ Animação de entrada nos elementos (slide-in)
